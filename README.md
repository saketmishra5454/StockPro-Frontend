# StockPro Frontend

Angular 17 enterprise SaaS frontend for the StockPro Inventory Management System.

This first phase contains the production-ready project setup and core architecture:

- Standalone Angular app
- Feature-based folders
- Lazy-loaded routes
- JWT auth foundation
- Role-based guards
- HTTP auth/error interceptor
- Global error handling
- Material + Tailwind styling
- Dark/light theme support
- Responsive SaaS shell
